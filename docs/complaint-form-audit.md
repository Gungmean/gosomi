원본의 서약문·안내문은 고정 문구이며, 고소인 성명은 마지막 성명란에 반영된다.

## 대화에서의 자동 체크

- 체크리스트 질문 카드를 새로 만들지 않는다. 핵심 사건 정보만 필요할 때 확인한다.
- AI 체크에는 사용자 발언의 원문 근거가 필요하다. 실제 사용자 메시지에 없는 근거는 수용하지 않는다.
- 명확한 목격자·CCTV·관계·과거 신고·취소 의사 등은 사용자 발언에서 별도로 추출한다.
- 언급이 없거나 불확실하면 빈칸을 유지한다. 합의 후 취소 의사와 과거 취소 이력을 구별한다.
- 직접 수정하거나 지운 선택은 자동 반영으로 덮어쓰지 않는다.
- 기존 대화를 다시 열 때도 명시된 사실로 빈 체크리스트를 보충하되 기존 선택을 유지한다.

## 검증

- `node scripts/verify-complaint-pdf.mjs`: PDF 글자 좌표와 모든 원본 체크박스를 대조한다. 사기 29개, 명예훼손 23개, 폭행 43개를 각각 중복 없이 연결했다. 체크리스트는 8/10/7개이다.
- `node --test server/*.test.mjs`: 자동 추출, 부정·불확실성, 근거 검증, 수동 수정 보존, 채팅 API, 복수 선택, 날짜·시간 분리 및 이전 데이터 호환을 검증한다.
- `npm run build`: TypeScript와 배포 빌드를 검증한다.
- 실제 브라우저에서 각 원본 페이지와 10–14쪽 별지를 렌더링했다. 세 유형의 텍스트 영역에 가로·세로 넘침이 없음을 확인했다.
- 원본의 텍스트 칸을 누르면 대응 입력란에 포커스가 이동함을 확인했다.
- 390px 모바일에서 가로 넘침 없이 작성·미리보기가 동작함을 확인했다.
- 추가 명단, 병원 횟수, 복수 선택 및 12,000자 이상의 반복 원문이 QR 인코딩·디코딩 후 유지됨을 확인했다.
- 앱의 실제 다운로드 버튼으로 세 유형의 A4 PDF를 생성하고 다시 PNG로 렌더링해 원본 칸·체크 위치·페이지 경계·전체 내용 별지를 확인했다. 내보내기는 원본 이미지와 좌표를 직접 사용하며, 긴 별지는 줄 단위로 페이지를 나눈다.

검증 중 발견한 PDF 축소, 텍스트 잘림, 빈 페이지 및 원본 페이지 연결 문제를 수정했다.
QR 하나에 담을 수 없는 분량은 문서 내용을 잘라 넣지 않고 오류를 표시한다.
