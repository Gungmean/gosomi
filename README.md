# 고소미

사건을 대화로 정리하고 고소장 초안을 실시간으로 보여주는 로컬 웹 앱입니다. 판례 검색은 국가법령정보센터의 공개 형사 판례를 조회합니다.

## 실행

Node.js와 npm이 필요합니다.

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다. 개발 서버와 API 서버가 함께 시작됩니다. 배포용 프런트엔드 생성은 `npm run build`입니다.
빌드 결과를 API 서버와 함께 미리 확인하려면 `npm run preview`를 실행한 뒤 `http://127.0.0.1:4173/`을 엽니다.

## 설정

- AI 대화를 사용하려면 화면 왼쪽 아래 **API 연결 설정**에서 본인의 OpenAI, Anthropic 또는 Gemini API 키를 입력합니다. 키는 브라우저 로컬 저장소에 암호화 없이 저장되며 새로고침 후에도 유지됩니다. 공유 기기에서는 사용 후 키를 지우세요.
- 판례 검색은 AI 키 없이 사용할 수 있습니다. 기본 실행에서는 국가법령정보센터의 예제 인증값 `test`를 사용합니다. 실제 배포 전에는 [국가법령정보 공동활용](https://open.law.go.kr/)에서 인증값을 발급받아 `.env` 파일에 `LAW_API_OC=발급받은값`을 설정해야 합니다. 예시는 [.env.example](.env.example)에 있습니다.
- 대화와 초안은 현재 브라우저의 로컬 저장소에 저장됩니다. 같은 기기의 다른 브라우저나 계정으로 동기화되지 않습니다. 사건 내용은 AI 기능을 사용할 때 선택한 AI 제공자로 전송됩니다.

## 주요 기능

- 대화 목록, 새 대화, 이름 변경, 삭제
- 사용자 API 키를 통한 AI 사건 정리와 고소장 항목 채우기
- 경찰청 간이 고소장 원본 페이지를 사용하는 사기·모욕/명예훼손·폭행 양식 미리보기와 일반형 초안
- 오른쪽 가장자리 손잡이로 여는 실시간 문서 미리보기와 직접 수정
- 공개 형사 판례 검색, 사건번호·선고일·공식 원문 링크
- 브라우저 인쇄 기능을 통한 PDF 저장
- 고소장 수령 대응 모드: 여러 장의 PDF·JPG·PNG·WebP 파일 첨부, 원본 미리보기, PDF 텍스트 추출 및 사진·스캔 페이지의 AI 이미지 분석, 대응 메모 자동 반영

## 현재 범위

사기·모욕/명예훼손·폭행 미리보기는 경찰청이 공개한 간이 고소장 원본 2쪽을 배경으로 표시하고, 입력한 내용을 해당 칸 위에 반영합니다. 인쇄 시 A4 2쪽으로 출력되며, 주민등록번호 등 민감 정보는 미리 입력받지 않고 출력 후 직접 작성하도록 안내합니다. 공식 양식이 없는 일반형은 별도 초안으로 표시합니다. 실제 제출 전에는 [경찰청 원본 안내](https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1002&q_bbscttSn=20240617160750770)에서 최신 양식을 확인하세요. 미리보기·인쇄 배경은 원본 PDF에서 렌더링한 이미지입니다.

판례 검색은 공개 판례 범위에 한정됩니다. 검색어와 사건의 관련성을 완전히 판정하지 못하므로 결과 카드에서 원문을 확인해야 합니다. AI 답변은 법률정보와 작성 보조이며 법률 자문이나 대리를 제공하지 않습니다.

받은 고소장 파일은 대화당 최대 12쪽, 파일당 20MB까지 현재 브라우저의 IndexedDB에 보관합니다. 분석할 때 PDF에 포함된 글자와 사진·스캔 페이지 이미지가 선택한 AI 제공자로 전송됩니다. 원본은 첨부 목록에서 확인·삭제할 수 있고 대화를 삭제하면 해당 원본도 삭제합니다. AI의 문서 읽기는 오류가 있을 수 있으므로 원본과 반드시 대조하세요. 고소장과 대응 메모에는 맑은 고딕을 사용하며 설치되지 않은 환경에서는 Pretendard로 대체됩니다.

## 구성

- `src/`: React UI, 대화·초안 로컬 저장
- `server/index.mjs`: AI 제공자와 국가법령정보센터 API 중계
- `public/fonts/`: 제공된 Pretendard 웹폰트와 라이선스
- `고소미_기획서.md`: 제품 기획과 구현 현황
